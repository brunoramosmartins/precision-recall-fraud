## Datasets Used

### 1. Kaggle Credit Card Fraud Detection (real data)

**Source:** [https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
**License:** DbCL v1.0 — open for research and non-commercial use.
**Citation:** Dal Pozzolo et al. (2015). *Calibrating Probability with Undersampling for Unbalanced Classification.* IEEE Symposium on Computational Intelligence and Data Mining.

**Why it is not committed to this repository:**
The dataset is 143 MB. Committing large binary files to a public repository violates the DbCL license terms for redistribution and creates unnecessary repository bloat.

**How to download:**

Option 1 — Kaggle API (recommended):
```bash
pip install kaggle
kaggle datasets download -d mlg-ulb/creditcardfraud
unzip creditcardfraud.zip -d data/raw/
```

Option 2 — Manual download:
1. Go to: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
2. Click "Download".
3. Unzip and place `creditcard.csv` in `data/raw/creditcard.csv`.

**Expected path after download:**
```
data/raw/creditcard.csv
```
