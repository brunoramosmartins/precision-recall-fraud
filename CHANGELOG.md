## [Unreleased] — Phase 0: Foundation & Setup

### Added
- Repository initialized with README, LICENSE (MIT), and base structure.
- `.github/pull_request_template.md` — PR checklist template.
- `.github/ISSUE_TEMPLATE/content.md` — Issue template for theory/writing tasks.
- `.github/ISSUE_TEMPLATE/code.md` — Issue template for code/experiment tasks.
- `.gitignore` — Python project and LaTeX build artifact ignore rules.
- `LICENSE-TEXT` — CC BY 4.0 for article text.
- `CONTRIBUTING.md` — Branch naming, commit conventions, code standards.
- Full folder structure: `article/`, `article/latex/`, `docs/`, `src/`, `scripts/`, `notebooks/`, `figures/`, `data/`, `notes/`.
- `requirements.txt` — Python dependencies with pinned versions.
- `config.yaml` — Seeds, paths, threshold ranges, figure settings, cost matrix.
- `docs/thesis.md` — Thesis statement, scope, reader persona, promise to reader, publishing plan.
- `docs/outline.md` — Article skeleton with section summaries.
- `docs/dataset-decision.md` — Dataset shortlist, criteria, and final decision (Option C: both datasets).
- `docs/index.html` — GitHub Pages landing page for the repository.
- `data/README.md` — Data sources, licenses, download instructions.
